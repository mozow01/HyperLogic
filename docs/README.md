# Historical documentation

The older coqdoc HTML pages, PDFs, and TeX article here are retained as
historical working notes. They were written against earlier stages of the
formalization; theorem names, hypotheses, and navigation links may differ
from the current library. In particular, the old coqdoc snapshot is incomplete.

For current statements, read the tracked `.v` files under `theories/`. The
supported source set is `_CoqProject`; setup and verification commands are in
[the repository README](../README.md). The [documentation index](index.html)
links to the main current source files and the historical reports.
